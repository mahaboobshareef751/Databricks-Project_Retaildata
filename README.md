### Databricks-Project_Retaildata

### Retail Sales Analytics Platform using Medallion Architecture in Databricks

## Bronze Layer
Stores raw data ingested from source systems.
Data is maintained in its original format with minimal transformations.
## Silver Layer
Stores cleaned, validated, and transformed data.
Handles data quality checks, deduplication, and standardization.
## Gold Layer
Stores business-ready, aggregated, and optimized datasets.
Used for reporting, analytics, dashboards, and downstream consumption.
Provides high-performance access to curated data.
